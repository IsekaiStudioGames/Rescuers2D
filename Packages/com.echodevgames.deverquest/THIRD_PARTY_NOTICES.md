# DeverQuest Third-Party Notices

**Package version:** 0.32.5 Beta 1

## Bundled third-party media

No third-party music, ambience, warning sound, image, font, or other media file
is bundled in the DeverQuest 0.32.5 package tarball. DeverQuest provides fields
that allow project administrators to assign their own Unity assets.

## Local development and test media

The project owner has identified RPG Sounds, SEGA soundtracks, and Loudlib as
local test or candidate sources. These names are recorded for license review
only. Files from those sources must not be added to the distributed package or
public repository until the exact asset, creator, source, license, attribution
requirements, and redistribution rights have been documented.

## AI assistance

ChatGPT by OpenAI was used as a development and documentation assistant. It is
not embedded as a runtime dependency and does not ship as third-party code in
the Unity package.

## Administrator responsibility

DeverQuest administrators are responsible for the rights to assets they import
into playlists, warning profiles, ambience profiles, portraits, or other custom
content. User-imported assets are not automatically licensed for redistribution.
