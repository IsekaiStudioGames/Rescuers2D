# Index

## Purpose

This document is the central navigation hub for the Rescuers2D design wiki. All other documents should be reachable from here.

## Overview

Rescuers2D documentation is organized into thirteen linked pages covering rules, characters, level design, items, puzzles, enemies, hazards, death/failure states, level codes, and the project's disaster relief context.
